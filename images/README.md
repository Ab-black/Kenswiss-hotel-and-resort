# Kenswiss Hotel & Resort image assets

This folder is reserved for approved photographs and brand assets supplied by the hotel or used with permission.

## Suggested filenames

- `kenswiss-logo.svg` — approved hotel logo
- `hotel-exterior.jpg` — actual exterior / entrance
- `hotel-reception.jpg` — reception or lobby
- `room-comfort.jpg` — confirmed room category
- `room-deluxe.jpg` — confirmed room category, if offered
- `hotel-dining.jpg` — dining area, if offered
- `hotel-amenities.jpg` — verified facilities
- `hotel-gallery-01.jpg` — approved gallery photographs

The current homepage uses temporary Unsplash image URLs directly in the HTML. They are illustrative design assets, not photographs of Kenswiss Hotel & Resort. Once approved hotel images are available, add them here and update the image paths in `index.html`.

Do not copy Google Maps user photographs into this repository unless the photographer or rights holder has authorized reuse.
